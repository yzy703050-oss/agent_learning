# Analytics skill signals

For data analyst roles, Python and SQL usually signal data cleaning, transformation, querying, and analysis ability.

Tableau, Power BI, and Excel usually signal reporting, dashboarding, business communication, and stakeholder-facing work.

A/B testing, experimentation, statistics, and product metrics signal stronger fit for product analyst, growth analyst, and experimentation-focused analytics roles.

Pandas, NumPy, notebooks, and reproducible analysis workflows help support Python claims with concrete project evidence.
